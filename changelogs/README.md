# 変更履歴アーカイブ

このディレクトリには古いバージョンの変更履歴を保管します。

`CHANGELOG.md` が長くなりすぎた場合、完了済みバージョンのエントリをマイナーバージョン単位でこちらに移してください。

## ファイル一覧

| ファイル | バージョン |
|---|---|
| `0.1.x.md` | 0.1.0 - 0.1.x |

## アーカイブ手順

1. `CHANGELOG.md` からバージョンエントリを切り取る（`[Unreleased]` と最新リリースは残す）
2. `X.Y.x.md`（例: `1.3.x.md`）という名前でファイルを作成する
3. 切り取ったエントリを新ファイルに貼り付ける
4. 上記のファイル一覧を更新する
